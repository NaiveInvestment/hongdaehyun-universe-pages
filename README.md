# 홍대현 Universe — 공개 스냅샷

이 저장소에는 **빌드 산출물만** 들어 있습니다. 소스와 키는 별도 private 저장소에 있습니다.

- 실시간이 아닙니다. 화면에 표시된 **기준 시각의 지연 스냅샷**입니다.
- 개인 모니터링용이며 투자 권유가 아닙니다. 주문·계좌 기능은 없습니다.
- 시세는 Kiwoom·NAVER, 컨센서스는 ConsenDB, 확정 실적은 OpenDART에서 왔습니다.
- `robots.txt`와 `noindex`로 검색 엔진 색인을 거부합니다.

산출물은 PC에서 `scripts/publish-static.mjs`로 밀어 올리고, GitHub Actions는 Pages 배포만 합니다.
